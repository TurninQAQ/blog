## Decisions Made

- `/notes/[slug]` uses the existing public query boundary in both `generateMetadata()` and the page component so unpublished records stay indistinguishable from missing slugs.
- Article pages reuse `renderPublicMarkdown()` and pass its rendered React content into `ArticleMarkdown`, avoiding a second renderer or unsafe HTML path.
- The TOC is rendered server-side twice from the same heading data: a desktop sticky rail and a mobile in-flow disclosure before the article body.
