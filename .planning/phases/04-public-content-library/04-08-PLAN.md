|----------|-------------|
| browser -> `/search` | Untrusted query text becomes Prisma filters. |
| stored post state -> public search/homepage | Draft and published states cross into public modules. |
| admin mutation results -> homepage/search surfaces | Publication changes become visible through live reads and revalidation. |
