## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser -> mutation route | Authenticated admin actions change public visibility. |
| mutation route -> Prisma | Validated admin input changes durable post state. |
| mutation route -> public route cache | Mutation code invalidates public pages after state changes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-07-01 | Spoofing / CSRF | admin publish/unpublish routes | high | mitigate | Preserve route origin rejection and `requireAdmin()` first in the dispatcher; tests cover unauthorized and cross-origin requests. |
| T-04-07-02 | Tampering | publish/unpublish mutations | high | mitigate | Parse `{ id }` with zod, read previous state before update, preserve first `publishedAt`, and write only after admin authorization. |
| T-04-07-03 | Information Disclosure | stale public pages | medium | mitigate | Compute old and new affected paths and call `revalidatePath` for public indexes and details. |
| T-04-SC | Tampering | npm installs | high | mitigate | No package installation is authorized in this plan. |
</threat_model>
