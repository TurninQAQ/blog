## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| package registry -> repo | New npm packages enter the trusted build graph. |
| .env.local -> server runtime | Local secrets become auth/database configuration. |
| server runtime -> PostgreSQL | Prisma migrations and queries can create or mutate durable data. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
