<tasks>

2. Implement an admin upload route whose order is Origin check, admin authentication, request bounds, multipart parsing, signature/decode/dimension checks, EXIF-stripping WebP transcode, then Prisma write.
3. Serve unpublished assets only to the administrator with `private, no-store`; serve first-published assets with immutable cache, strong ETag, fixed MIME, and `nosniff`; unknown/private anonymous requests return 404.
4. Replace the inline URL form with an accessible image modal and one upload function shared by local selection, drop, and paste. Persist only returned `/media/*.webp` URLs, never blob/data URLs.
5. Mark referenced managed assets public when a post is first published or an already-published post is edited; never fetch external URLs.
