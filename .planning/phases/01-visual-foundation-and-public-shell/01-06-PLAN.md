## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> homepage canvas | Browser pointer, viewport, visibility, and media-query state affect client animation code. |
| Browser -> public route surfaces | Public visitors request shell pages that must not load homepage-only effect code. |
| Package manifest -> browser bundle | Dependencies and imports determine whether WebGL/Three code enters the public app. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | npm installs | high | mitigate | No package-manager install occurs in this plan; dependency is transferred to Plan 01-01 blocking package checkpoint, and this plan verifies banned WebGL dependencies are absent. |
| T-01-13 | Denial of Service | `SignalNetworkCanvas` | medium | mitigate | Cap DPR/counts, use `requestAnimationFrame`, pause hidden/offscreen, disable in reduced motion, and clean up listeners/observers. |
| T-01-14 | Information Disclosure | Canvas event handling | low | mitigate | Track only local pointer coordinates for visual attraction, do not send events over the network, and remove listeners on unmount. |
| T-01-15 | Denial of Service | Reduced-motion/mobile users | medium | mitigate | CSS and JS reduced-motion branches disable canvas animation, parallax, pointer-follow, hover lift, and scanline loops; Playwright verifies mobile/reduced-motion. |
| T-01-16 | Tampering | Homepage effect isolation | medium | mitigate | Mount canvas only from the homepage hero and verify route surfaces do not contain the signal canvas element. |
</threat_model>
