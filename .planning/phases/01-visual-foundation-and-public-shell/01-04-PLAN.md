## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public browser -> public shell | Untrusted visitors request pages wrapped by the shell. |
| Public browser -> navigation links | Visitors follow route links or email link rendered by the shell. |
| Keyboard user -> mobile nav client component | Browser events control menu state and focus movement. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | npm installs | high | mitigate | No package-manager install occurs in this plan; package approval and install are handled by Plans 01-01 and 01-02. |
| T-01-07 | Spoofing | `src/config/routes.ts`, public nav | medium | mitigate | Render only real internal links for Notes, Series, Archive, and Search; do not add fake external/project/social destinations. |
| T-01-08 | Information Disclosure | Public copy/config | low | mitigate | Expose only public brand/email/copy; do not read or render env vars, secrets, admin paths, or runtime diagnostics. |
| T-01-09 | Denial of Service | `MobileNav` keyboard/focus flow | medium | mitigate | Implement Escape close, focus containment, focus return, visible focus rings, and 44px tap targets; verify with Playwright. |
</threat_model>
