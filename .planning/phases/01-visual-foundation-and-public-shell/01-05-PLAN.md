## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public browser -> public routes | Untrusted visitors request homepage and empty-state route surfaces. |
| Public browser -> content route links | Visitors follow internal route links rendered by homepage and route cards. |
| Static preview copy -> reader perception | Generic preview content must not misrepresent itself as published content. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | npm installs | high | mitigate | No package-manager install occurs in this plan; package approval and install are handled by Plans 01-01 and 01-02. |
| T-01-10 | Spoofing | `ContentRouteStrip`, `FeaturedNoteCard` | medium | mitigate | Render only real internal route links and editorial system-module copy; avoid fake post metadata or fake external destinations. |
| T-01-11 | Information Disclosure | Homepage and route pages | low | mitigate | Expose only public brand/email/copy; do not read or render env vars, secrets, admin paths, runtime diagnostics, or local skeleton state. |
| T-01-12 | Tampering | `ArticlePreviewShell` | low | mitigate | Keep preview content static and generic; do not render raw user content or unsafe HTML in Phase 1. |
</threat_model>
