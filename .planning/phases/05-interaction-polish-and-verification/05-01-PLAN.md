<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet/load balancer -> health routes | Unauthenticated probes reach process and database connectivity checks. |
| repository/lockfile -> CI runner | CI installs and executes code defined by the committed dependency graph. |
| CI runtime -> disposable PostgreSQL/admin session | Generated test credentials cross into an ephemeral database and browser session. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01-01 | Information Disclosure | health routes | medium | mitigate | Return exact generic states, no-store headers, and no caught error or environment detail; cover response keys in Playwright. |
| T-05-01-02 | Denial of Service | readiness database probe | medium | mitigate | Use one bounded read-only query and leave request-rate/concurrency enforcement to the D-14 provider gate documented by the security audit. |
| T-05-01-03 | Information Disclosure | CI credentials | high | mitigate | Generate test-only values at runtime, avoid logging them, scan tracked files, and use an ephemeral database. |
| T-05-01-04 | Tampering | application lockfile cleanup | medium | mitigate | Regenerate with npm, use `npm ci`, and verify the removed application node is absent without touching global GSD. |
| T-05-SC | Tampering | npm execution | high | mitigate | Add no package; CI consumes the existing reviewed lockfile with `npm ci`, source scan, and high-threshold audits. |
</threat_model>
