**As a** site owner, **I want to** write Markdown in a protected editor and see a safe live preview with article-like typography, **so that** technical notes can be drafted with confidence before public rendering is built.

Purpose: This upgrades the draft editor from a plain textarea to the selected Markdown authoring experience without leaking editor packages into public routes.
Output: Approved package install, admin-only Markdown editor client component, shared safe preview component, markdown policy helper, preview styling, and Playwright/source-scan verification.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry -> build graph | New Markdown/editor packages become trusted code. |
| admin browser editor -> preview renderer | Untrusted Markdown text is rendered in the browser while editing. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-03-02-01 | Tampering | npm package install | high | mitigate | Blocking metadata checkpoint before package installation. |
| T-03-02-02 | Elevation of Privilege | Markdown raw HTML | high | mitigate | Do not use `rehype-raw`; add raw HTML fixture test and block `dangerouslySetInnerHTML`. |
| T-03-02-03 | Information Disclosure | Public bundle/source | medium | mitigate | Source scan blocks `@uiw/react-md-editor` imports from public/shared public paths. |
