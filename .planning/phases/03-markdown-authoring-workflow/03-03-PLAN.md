## Phase Goal

**As a** site owner, **I want to** assign categories, tags, and optional series ordering while editing a draft, **so that** technical notes can be organized from the same writing workflow without separate taxonomy management pages.

<objective>
Add inline taxonomy and series assignment to the protected draft editor: one category, multiple tags, optional series, manual series order, inline creation, duplicate handling, persistence, and dashboard/list metadata display.

Purpose: This completes Phase 3 content organization without adding standalone taxonomy pages or public browsing behavior.
Output: Taxonomy picker components, series order input, expanded post input schemas, transactional save behavior, duplicate taxonomy/order validation, and Playwright coverage.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| admin browser -> taxonomy inputs | User-entered taxonomy names and ids are untrusted. |
| mutation dispatcher -> taxonomy tables | Inline creation mutates `Category`, `Tag`, `Series`, and `PostTag` records. |
| editor organization metadata -> public scope | Metadata exists for future public routes but must not publish or expose drafts in Phase 3. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03-01 | Tampering | Taxonomy ids/names | medium | mitigate | Server schemas validate ids/names and resolve/create records inside the guarded mutation transaction. |
| T-03-03-02 | Tampering | Duplicate taxonomy slugs | medium | mitigate | Normalize slugs and return field-level duplicate errors instead of uncaught Prisma exceptions. |
| T-03-03-03 | Tampering | Series order | medium | mitigate | Validate duplicate `seriesOrder` in the selected series, excluding the current post during edit. |
| T-03-03-04 | Information Disclosure | Draft metadata | medium | mitigate | This plan adds no public taxonomy pages and no published-only query surfaces. |
| T-03-03-05 | Elevation of Privilege | Taxonomy mutation endpoint | high | mitigate | Taxonomy creation is only reachable through the existing guarded post save flow after `requireAdmin()`. |
</threat_model>
