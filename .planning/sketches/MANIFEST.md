# Sketch Manifest

## Design Direction

Admin article authoring has moved away from a left-source/right-preview split and now uses a focused, Chinese, programmer-friendly WYSIWYG writing surface. The goal is a Typora-like feeling: the author edits the rendered article shape directly, Markdown remains the storage format, and unsupported legacy Markdown is blocked by a compatibility gate rather than edited through a source fallback.

## Reference Points

- Typora for inline article-like editing.
- Current Personal Tech Lab admin visual language: dark technical lab surfaces, restrained glow, compact controls, Chinese labels.
- Programmer note-taking needs: headings, code blocks, tables, links, tags, category, series, and reliable Markdown output.
